# GoldenRuler 黄金比例尺子

一款类似 Atrise Golden Section 的屏幕测量工具，用 C# + WinForms 开发，单文件绿色运行。

## 功能特性

### 网格模式（6种）
| 模式 | 说明 | 快捷键 |
|------|------|--------|
| 经典 | 基础参考线 | D1 |
| 黄金分割 | 黄金比例分割线 + 边界矩形 + 对角线 | D2 |
| 固定网格 | 可调节尺寸的方块网格 | D3 |
| 方块 | 等比例方块 | D4 |
| 螺旋 | 黄金螺旋线 | D5 |
| 圆环 | 同心圆 + 黄金分割线 | D6 |

- **Enter** 循环切换下一个模式
- **空格** 切换网格起点（左上/右上/左下/右下）

### 移动与定位

| 右移 | D | |

| 微调右 | Shift+D | |

| 微调下 | Shift+S | |

### 把手操作（右下角/左上角）
- **拖动**：调整窗口大小
- **Shift + 拖动**：按比例缩放
- **Alt + 拖动**：以中心为锚点对称扩展
- **Ctrl + 拖动**：移动窗口
- **按住把手 + WASD**：以把手为锚点扩展/收缩窗口
- **鼠标滚轮（在把手/标题栏上）**：调节网格尺寸

### 黄金辅助线
| 操作 | 默认快捷键 | 说明 |
|------|-----------|------|
| 横向黄金线 | Alt+Q | 在窗口高度的黄金分割点绘制横向线，3秒后消失 |
| 竖向黄金线 | Alt+W | 在窗口宽度的黄金分割点绘制竖向线，3秒后消失 |

- 辅助线始终 100% 不透明，不受主窗口透明度影响
- 辅助线跟随旋转角度
- 两条线可以同时显示

- 线条粗细（0.5~5.0px）
- 线条模式（双色/单色）
- 单色线颜色
- 黄金辅助线颜色
- 焦点描边颜色
- 网格模式
- 网格起点
- 网格尺寸
- **所有热键均可自定义**

## 架构说明

### 窗口组成
```
RulerForm（主窗口）
  ├─ GripPadForm × 2（把手热区窗口，左上+右下）
  └─ GoldenOverlayForm（黄金辅助线窗口）
```

**主窗口**：使用 `LWA_COLORKEY | LWA_ALPHA` 双层透明
- Fuchsia 色 = 完全透明（色彩键）
- 其他像素 = 受整体 alpha 控制
- 优点：性能好、实现简单
- 限制：透明像素不接收鼠标事件

**把手热区窗口（GripPadForm）**：使用 `LWA_ALPHA`，alpha=1
- 几乎不可见，但整个矩形区域都能接收鼠标事件
- 解决了"透明区域无法点击"的问题
- 用 `SetWindowPos + SWP_NOACTIVATE` 控制位置，不抢焦点

**黄金辅助线窗口（GoldenOverlayForm）**：使用 `LWA_COLORKEY` 无 alpha
- 辅助线始终 100% 不透明，不受主窗口透明度影响
- `WS_EX_TRANSPARENT` 让鼠标穿透

### 关键技术点
- **双击缓冲**：`DoubleBuffered + OptimizedDoubleBuffer`，无闪烁
- **拖动丝滑**：类背景画刷 + `this.Update()` 同步绘制，无黑边
- **物理鼠标检测**：`GetAsyncKeyState(VK_LBUTTON)` 防止虚假 WM_LBUTTONUP
- **全局热键**：`RegisterHotKey` 实现全局热键
- **持久化**：XML 序列化保存所有设置

## 编译方式

需要 .NET Framework 4.x（Win10/Win11 自带）。

```bash
cd GoldenRuler
csc -target:winexe -out:GoldenRuler.exe -reference:System.Windows.Forms.dll -reference:System.Drawing.dll -reference:System.dll GoldenRuler.cs
```

编译产物就是单个 `GoldenRuler.exe`，绿色运行，无需安装。

## 已知注意事项

### Quicker 等鼠标增强软件冲突
Quicker 的"左键辅助"功能会在按住左键时拦截键盘按键，导致把手+WASD 功能异常。
解决：在 Quicker 中关闭冲突的按键规则，或把 GoldenRuler 加入排除列表。

### 外部软件全局热键冲突
如果某个热键异常（其他键正常，就这个键不行），先排查是否有全局热键软件冲突。
